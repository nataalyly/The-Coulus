# 🚀 The Coulus — 2D Space Shooter

**The Coulus** adalah game 2D shooter bergaya arcade dengan pixel art, di mana kamu mengendalikan pesawat untuk mengalahkan musuh dan meraih skor setinggi mungkin.

---

## 🎮 Gameplay

* Kendalikan pesawat dan tembak musuh yang datang
* Hindari tabrakan agar tidak kehilangan nyawa
* Kumpulkan skor sebanyak mungkin
* Capai **High Score** tertinggi!

---

## 🕹️ Controls

* **Move**: WASD
* **Shoot**: Space / Mouse Left-Click

---

## ✨ Features

* 🔫 Shooting mechanic
* 👾 Enemy spawning system
* ❤️ HP / Life system
* 🏆 High Score system (tersimpan)
* ⏸️ Pause & Resume
* 🔊 Sound effects & BGM
